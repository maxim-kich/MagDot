# Security

Please report vulnerabilities privately using GitHub's private vulnerability reporting once enabled for this repository. Do not post credentials or exploit details in public issues. If private reporting is unavailable, open a minimal issue asking for a private contact channel without sensitive details.

MagDot's helper runs as root and is restricted to the ACLC LED key. Report any bypass of signed-client verification, access to other SMC keys, arbitrary command execution, or unexpected persistent writes. No security audit is claimed.

Only tagged release artifacts explicitly described as supported are distribution builds. Local/CI validation artifacts are not supported releases.
