# MagDot 0.0.2

A smoother, more responsive MagDot, with clearer activation feedback and more reliable completion notifications.

- **Lower CPU use:** more efficient T3 status tracking and Settings refreshes.
- **Reliable Done notifications:** completed threads keep blinking until they are read, snoozed, settled, or the selected duration expires. Acknowledging one thread leaves other pending completions visible.
- **Clearer activation:** the Activate switch stays on while the helper starts or waits for approval. Startup failures show an explanation and can be retried.
- **Simpler setup:** onboarding stays separate from Settings, and helper registration no longer also forces System Settings to open.
- **Centered speed controls:** 1.00× sits at the middle of each state slider. Existing saved timings are preserved.
- **Dock visibility fix:** Settings stays open when Hide from Dock is switched on.

Requires an Apple Silicon Mac, macOS 14 or later, an official MagSafe 3 cable, and local T3 Code for automatic status tracking.
